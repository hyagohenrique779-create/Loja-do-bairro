### Regra de WIP (Work In Progress)
A coluna **In progress** possui o limite máximo de **3 tarefas simultâneas**. Caso o limite seja atingido, nenhum integrante pode puxar novas tarefas de *Ready* até que um item em andamento seja finalizado ou movido para *In review*.
